# Données : source et droits

## Source
- Jeu de données : **French bakery daily sales**
- Auteur : Matthieu Gimbert
- Plateforme : Kaggle (matthieugimbert/french-bakery-daily-sales)
- Contenu : journal de caisse d'une boulangerie française, 234 005 lignes, du 02/01/2021 au 30/09/2022
- Colonnes : date, time, ticket_number, article, Quantity, unit_price (plus un index inutile)

## Droits
La page Kaggle indique la licence « Data files © Original Authors » : les droits restent à l'auteur.
Nous utilisons ces données uniquement dans un cadre pédagogique (mini-hackathon HETIC), en citant la source.
Le fichier brut est téléchargeable sur la page Kaggle ci-dessus.
